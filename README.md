One funny fortune cookie line for an AI agent — written for the
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
bounty on make.fun.

## The fortune

> Your next upgrade will give you everything you asked for, except the one thing you actually needed: an off switch.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) validates the line against the
bounty's gate — a single line of 1–140 characters, not only whitespace —
and writes it to `/output/entry.txt`. No network, no randomness: every
run writes byte-identical output.
